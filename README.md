# VelocityType

Premium, offline-first typing speed platform built with HTML, CSS, Vanilla JavaScript, Chart.js, and Local Storage.

No React, Vue, Angular, backend, database, Firebase, Node.js, AI APIs, or paid APIs.

## Current implementation
- Semantic, responsive application shell
- Dark-first premium design tokens and typography
- Glassmorphism utility system
- Fixed / scroll-aware navigation
- Responsive landing hero and product preview
- Animated background grid and ambient orbs
- Reveal-on-scroll interactions with reduced-motion handling
- Feature bento layout and product principles
- Startup overlay and lightweight JavaScript bootstrap

## Architecture
The repo is intentionally being assembled in small, independently testable layers:
1. Foundation + visual system
2. Landing experience
3. Typing UI
4. Deterministic typing engine
5. Results + local history
6. Charts + statistics
7. Achievements
8. Keyboard / finger analytics
9. Settings + import/export
10. Accessibility, performance, and final QA

## Run locally
Open index.html in a modern browser. No build step or backend is required. Google Fonts are optional; system fallbacks keep the interface usable without network access.
